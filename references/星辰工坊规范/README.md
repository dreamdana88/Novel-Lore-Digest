# 星辰工坊规范（参考依据）

本目录收录角色卡 / 世界书模板所依据的星辰工坊原始规范，供没有安装星辰工坊预设的用户查阅引用。

星辰工坊原始规范与 Novel Lore Digest 由同一作者创作和维护。

| 文件 | 用途 | 对应模板 |
|---|---|---|
| `什么是世界书.yaml` | 世界书机制：插入位置/顺序/激活策略/递归激活 | `templates/worldbook-entry-template.md`、`worldbook-output-template.md` |
| `创世-世界书规范.txt` | 世界观构建流程：蓝灯总览→绿灯详情、PList 速写、条目格式 | 同上 |
| `捏人-主角色规范.txt` | 主角色卡 `<Character_>` 蓝图规范 | `templates/starforge-主角色卡-template.md` |
| `捏人-配角NPC规范.txt` | 配角 NPC 卡 `<NPC_>` 蓝图规范 | `templates/starforge-配角NPC卡-template.md` |

> 模板已按这些规范改写为「带来源、可复查、不编造」的分析→输出流程。
> 若星辰工坊原规范升级，更新这里的文件并同步调整对应模板即可。
