# 星辰工坊世界书规范（参考依据）

本目录仅保留世界书机制与构建规范，供没有安装星辰工坊预设的用户查阅引用。

星辰工坊原始规范与 Novel Lore Digest 由同一作者创作和维护。

| 文件 | 用途 | 对应模板 |
|---|---|---|
| `什么是世界书.yaml` | 世界书机制：插入位置/顺序/激活策略/递归激活 | `templates/worldbook-entry-template.md`、`worldbook-output-template.md` |
| `创世-世界书规范.txt` | 世界观构建流程：蓝灯总览→绿灯详情、PList 速写、条目格式 | 同上 |

角色生成规则统一见 `prompts/09_输出SillyTavern角色汇总.md`；字段结构与分档要求统一见 `templates/starforge-主角色卡-template.md`、`templates/starforge-配角NPC卡-template.md` 和 `templates/starforge-角色清单-template.md`。本目录不再另存一套角色生成规范。

若世界书原规范升级，更新这里的文件并同步调整对应世界书模板。
