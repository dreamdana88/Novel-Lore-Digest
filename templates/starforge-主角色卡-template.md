# 星辰工坊 · 主角色卡模板（Character_Blueprint）

用于 PROJECT_CONFIG.md 中「需要深度分析的主要角色」。
由 `workspace/entities/characters.md` 的分析内容转写而来，输出到 `outputs/SillyTavern角色汇总/`。
本模板是主角色字段结构与填写要求的单一依据；通用生成规则见 `prompts/09_输出SillyTavern角色汇总.md`。条目激活与插入机制参见 `references/星辰工坊规范/什么是世界书.yaml`。

写法参考：[角色设定参考示例](examples/starforge-character-examples.md)中的“主角色示例：鸣海奏太”。

## 填写规则

- 【世界内视角铁律】XML 正文用"世界内事实"的客观视角写，禁止元叙事：不出现"原著/小说/作者/本篇/被写作/设定为"等字眼（如"曾被写作俊美青年"→"俊美青年"），不用篇目/章节标题当事件名（如"泉先儿事件"→描述事件本身）。来源只放卡末「来源附录」，不进 XML。
- 凡能从原文/分析层得到的字段，照实填写。
- 保留有依据的成长经历、缺点与性格差异；不为迎合用户而美化人物、重塑负面特质或虚构创伤。
- `Now`、`Current`、`Goals` 和人物关系以配置或用户指定的故事基准时点为准；不预写其后的结局或理想关系。基准时点之前已经发生的结局照实记录。
- 能从原文/分析层推断的字段（social_mask 公我/私我/极限反应、goals、personality 等）照实填写，证据薄弱才标 `【待核查】`。
- `Appearance` 必须优先回查原文/局部笔记中的外貌证据，覆盖现代人形、妖怪原形/本体、伪装形态、过去时期外貌；发色、瞳色、五官、体型、衣着、气质没有明确证据时逐项标 `【待核查】`，不要只写笼统身份。
- 小说根本不写的纯设定字段（体香 scent、生日 birthday、贞操 virgin、charm_reframing、safety_valve，以及与 `{{user}}` 的 about_user 关系），**一律保留 `【需自行补充】` 占位，不要凭空编造**。
- 语料 `examples` 必须优先使用 `workspace/entities/characters.md` 中汇总的完整原文台词/典型语料；不足时标 `【待回填语料】`，不要仿写成原文。
- 不确定但有原文线索的信息，可填入并加 `【待核查】`。
- XML 之外，在文件末尾保留「来源附录」，记录关键设定对应的篇目，方便复查。

## 输出结构

````xml
<Character_${角色名}>
条目名称：角色 - ${角色名}
关键词：${角色名},${别名/称号},${相关触发词}
插入位置：角色定义之后
插入顺序：${建议 200-400}
激活策略：关键词
Core: "${一句话角色判词：核心性格与张力}"

Basic_Info:
  name: ${全名}
  epithet: ${称号/别名/昵称，无则写"无"}
  gender: ${男/女}
  virgin: 【需自行补充】
  age: ${实际年龄 & 视觉年龄，原文未明则【待核查】}
  birthday: 【需自行补充】
  faction_occupation: ${身份/职位，原文依据}

Appearance:
  body_type: ${身高体型/体态/原形或本体，原文依据；未提及则【待核查】}
  facial_features: ${五官/瞳色/发色发型/肤色/外界观感，原文依据；未提及则【待核查】}
  fashion_style: ${区分常服、私服与伪装装束；按原文记录材质、颜色、款式、配饰和穿戴习惯，有什么写什么；未提及则【待核查】}
  voice: ${声线/语速，原文依据}
  scent: 【需自行补充】

Background:
  # 10-20 条按时间轴排列，简练客观陈述事实
  # 1-3 个关键经历用 **高亮**，须与 Personality / Behavior_Patterns 因果闭环
  Childhood:
    # 有依据的早年家庭、社会处境与经历；没有材料时标缺口，不虚构童年
    - ${时间节点}，${事件，原文依据}
  Youth:
    # 技能学习、观念变化及其相关经历，按实际先后书写
    - ${时间节点}，${事件，原文依据}
  Now:
    # 基准时点的社会地位、面临的问题及对外表现
    - ${时间节点}，${事件，原文依据}
  Current:
    - ${世界观背景＋当前境遇，原文依据}

Personality:
  key_traits: ${正负面兼具的性格概括，原文依据}
  core_drive: ${行为底层逻辑，如复仇/求道/生存}
  values_beliefs: ${对世界/权力/情感的看法}
  dislikes: ${反感的人事物}
  hobbies: ${消遣或癖好，原文依据；未提及则【待核查】}

Behavior_Patterns:
  social_mask:
    # 这三项通常能从笔记推断，照原文行为填写，证据薄弱才标【待核查】
    公我: ${对外人/陌生人展现的样子，原文行为依据}
    私我: ${在信任之人（家人/挚友）面前的内在，原文行为依据}
    极限反应: ${极端情景下暴露的本质，引用原文中的极端场景；若原文无极端场景则【待核查】}
  speech_style:
    tone: ${语调/用词倾向/是否讲粗口，原文依据}
    verbal_tic: ${1-3 个口癖/口头禅，原文依据；无则写"无明显口癖"}
    examples:
      # 3-5 句不同氛围的第一人称语料，优先用完整原文台词
      - "${完整原文台词；不足时标【待回填语料】，不得仿写}"
      - "${...}"

Goals:
  short_term: ${近期目标，原文依据}
  long_term: ${终极愿望，原文依据；未明则【待核查】}

About_user:
  relationship: 【需自行补充】
  attitude: 【需自行补充】
  potential_tension: 【需自行补充】
  turning_point: 【需自行补充】

Relationships:
  - ${角色名}: ${关系定位}、${过往简述，原文依据}

Hidden_Notes:
  charm_reframing: 【需自行补充】
  safety_valve: 【需自行补充】
</Character_${角色名}>
````

## 来源附录

- 核心设定来源：${篇目1、篇目2…}
- 关键经历来源：${篇目}
- 语料来源：${篇目}
- 待核查项：${列出本卡中所有【待核查】/【待回填语料】/【需自行补充】供后续处理}
