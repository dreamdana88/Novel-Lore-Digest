# 星辰工坊世界书输出模板

整本 `outputs/SillyTavern世界书.md` 必须分成“可导入条目块”和“生成说明与检查”两大区域。这样同一份文件既方便复查，也方便脚本提取可导入内容。

## 文件结构

```md

插入顺序：10
激活策略：常驻
不可递归：是
防止进一步递归：是

...

## 生成说明与检查

### 生成说明

- 使用“🔵常驻总览索引 → 可选的🟢次级骨架 → 🟢关键词详情条目”的分层激活链。
- 每个条目的直接母条目必须在正文叙述或 PList `has(...)` 中自然埋入其主关键词；蓝灯只需提及直接子条目，禁止用“需要展开的关键词包括”这类元说明代替世界内容。
- 所有条目默认勾选“不可递归”和“防止进一步递归”；只有用户明确要求的例外可以取消勾选。
```

## 可导入条目块规则

- 这里只能放 XML 条目块。
- 不要放 Markdown 说明、代码围栏、检查表或自然语言标题。
- 每个条目块必须包含：
  - `条目名称：`
  - `关键词：`
  - `插入位置：`
  - `插入顺序：`
  - `激活策略：`
  - `不可递归：`
  - `防止进一步递归：`
  - `条目内容：`
- 每个🟢关键词条目的主关键词，必须出现在其直接母条目的条目内容中；若直接母条目为🟢条目，其主关键词必须沿母子链追溯到🔵常驻根条目。
- `不可递归`和`防止进一步递归`默认均为“是”；只有用户明确要求时才可改为“否”。
- 【世界内视角】条目内容必须客观、世界内书写：不出现"原著/小说/作者/本篇/被写作"等元叙事，不用篇目/章节标题当事件名。
- 来源**不进条目内容**，统一放到 `### 来源对照` 表里复查。

## 推荐生成顺序

1. 🔵世界基石：1 条常驻总览，插入位置“角色定义之前”，插入顺序 0-50。
2. 🔵运行法则：1-3 条常驻规则，插入位置“角色定义之前”，插入顺序 50-100。
3. 🔵空间骨架/总览索引：1-2 条常驻总览，插入位置“角色定义之前/之后”，插入顺序 100-200。
4. 🟢次级骨架：仅在需要承接下层详情时生成，在内容中自然提及直接子条目的主关键词。
5. 🟢详细档案：地点、组织、物种、物品、NPC、事件、关系、日常生活等关键词触发条目，插入位置“角色定义之后”，插入顺序 150-600。
6. 激活链检查：逐条核对直接母条目中的主关键词落点，以及沿母子链到蓝灯根条目的完整路径。
7. 递归设置检查：确认所有条目默认勾选“不可递归”和“防止进一步递归”，仅保留用户明确要求的例外。
